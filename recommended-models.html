How much memory?

The estimates assume one request with up to 8,192 tokens shared by instructions, tool definitions, history, input and reply. Lit Loop’s model budget includes weights, the attention cache and runtime working memory. The Mac configurations leave room for macOS, Codex and its tools. The 24 GB coding example adds room for an IDE and test processes.

Tested hardware. All three pinned models generated text through Lit Loop’s Codex picker route on a MacBook Pro with M1 Max and 32 GB of unified memory. The tests used short text prompts. The 8K budgets and suggested Mac configurations are planning estimates. Peak memory at 8K was not measured.

Apple lists these memory configurations for the M2 MacBook Air and the M4 Mac mini.
